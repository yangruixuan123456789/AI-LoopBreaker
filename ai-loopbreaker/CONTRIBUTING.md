# Contributing

**中文** | [English](CONTRIBUTING.en.md)

LoopBreaker 接受新的循环模式，但偏好少而可验证的规则。

## 新增提示词前

1. 用一段真实的多轮对话说明循环，而不只是描述一个模型缺点。
2. 指出哪两轮在重复，以及为什么没有产生新信息。
3. 确认现有 13 个模式没有覆盖它。
4. 定义可观察的触发条件、停止动作、最小求证动作和完成条件。
5. 在 `evals/cases.json` 中添加至少一个反例或正例。
6. 同时更新中文和英文提示词，并确保行为等价。
7. 更新 `prompts/manifest.json` 和 `llms.txt`。
8. 运行 `python3 scripts/validate_prompts.py`。

## 提示词要求

- 用工作状态而非人格形容词描述要求。
- 明确什么不算进展。
- 优先要求取证和可逆行动，不鼓励无依据决策。
- 不要要求 AI 绕过权限、安全策略或用户授权。
- 不要把长模板本身当成解决方案。
- 每个提示词维护独立的中英文正文，不在同一文件中混排；索引同时记录两种语言。

## Pull request

请说明：

- 新增或修改的循环模式；
- 它解决的具体误循环；
- 一个使用前后的对照；
- 是否可能导致更少追问、范围扩大或错误自信等副作用。
