# Changelog

## 0.3.0 - 2026-10-21

### English

- Added `LB-13 Fix Coverage` for local fixes that close one symptom but leave the same invariant broken across sibling paths and states.
- Added English and Chinese examples of a pagination fix that must cover every navigation mode.
- Added a fix-coverage evaluation case and core-protocol trigger.
- Added bilingual GitHub import instructions and release packaging support.

### 中文

- 新增 `LB-13 修复覆盖不全`，处理只关闭一处症状、却没有关闭同一业务不变量的问题。
- 增加分页筛选场景的中英文案例，覆盖所有导航方式。
- 增加修复完整性评测用例和核心协议触发条件。
- 增加中英文 GitHub 导入说明和发布打包支持。

## 0.2.0 - 2026-10-21

### English

- Added Chinese and English language variants for the core protocol, all 12 patterns, and tool adapters.
- Made prompt language and paired files explicit in the manifest.
- Added bilingual design notes, examples, contribution guidance, and validation.

### 中文

- 为核心协议、12 个专项提示词和工具接入片段增加中英文语言版本。
- 在清单中明确提示词语言和成对文件。
- 增加双语设计说明、案例、贡献指南和校验。

## 0.1.0 - 2026-10-21

- Added the core LoopBreaker state-management protocol.
- Added 12 reusable prompt patterns for recurring AI collaboration loops.
- Added adapters for `AGENTS.md`, Claude Code, Cursor, and generic chat.
- Added design notes, examples, evaluation cases, and a manifest validator.
